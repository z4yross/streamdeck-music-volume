# Contributing

Issues and pull requests are welcome. Keep changes small and focused; one topic per PR.

## Prerequisites

- Windows 10 or later (the plugin is Windows-only: WASAPI and Windows media controls)
- Node.js 20
- Stream Deck software 6.9 or later and a Stream Deck+ (the action is dial-only)
- Windows PowerShell 5.1 (ships with Windows) for the audio helper
- To rebuild the SMTC shim: the Windows 10 SDK (for `Windows.winmd`) and the .NET
  Framework `csc.exe` that ships with Windows

## Set up

```bash
git clone https://github.com/z4yross/streamdeck-music-volume.git
cd streamdeck-music-volume
npm install
npx streamdeck link com.z4yross.musicvol.sdPlugin   # symlinks the plugin into Stream Deck
npm run watch                                       # rebuilds and restarts the plugin on save
```

`streamdeck link` creates a junction in `%APPDATA%\Elgato\StreamDeck\Plugins`, so the
Stream Deck app runs straight from your working copy. If you already installed the
Marketplace build, uninstall it first; both use the same UUID.

## Project layout

| Path | What |
| --- | --- |
| `src/plugin.ts` | Entry point: registers the action and connects |
| `src/actions/dial.ts` | The dial: state per dial, polling, gestures, coalesced volume writes, painting |
| `src/audio-bridge.ts` | Owns the long-lived PowerShell helper; one command in, one JSON line out |
| `src/icons.ts` | Player colours and fallback icons |
| `com.z4yross.musicvol.sdPlugin/bin/audio-bridge.ps1` | The helper: WASAPI per-app volume and SMTC metadata. Checked in, not generated |
| `com.z4yross.musicvol.sdPlugin/bin/smtc/` | `Smtc.cs`, the compiled `Smtc.dll` and `build.cmd` |
| `com.z4yross.musicvol.sdPlugin/` | What ships: manifest, layout, property inspector, images |
| `marketplace/` | Listing assets and copy for the Elgato Marketplace |

`bin/plugin.js` is generated by Rollup and ignored by git. The `.ps1` and `smtc/` files in
`bin/` are source and are tracked.

## The helper protocol

`audio-bridge.ps1` reads one command per line on stdin and answers one JSON line on
stdout. You can drive it by hand:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File com.z4yross.musicvol.sdPlugin\bin\audio-bridge.ps1
status Spotify,Deezer
set Spotify 0.5
mute Spotify toggle
ctl Spotify next
art Spotify
list
ping
```

The full command list is in the header comment of the script. If you change the
protocol, change `src/audio-bridge.ts` in the same PR.

### Rebuilding `Smtc.dll`

After editing `Smtc.cs`, run `bin\smtc\build.cmd`. It needs
`C:\Program Files (x86)\Windows Kits\10\UnionMetadata\<version>\Windows.winmd`; adjust the
version inside the script if yours differs. Commit the rebuilt DLL together with the
source so the shipped binary always matches.

## Debugging

- Logs: `com.z4yross.musicvol.sdPlugin/logs/`. The level is set to `debug` in `plugin.ts`.
  The dial logs only when the followed app or track changes, to keep it readable at a
  one-second poll.
- Node inspector: the manifest starts Node with `--inspect=127.0.0.1:12347`. Attach from
  VS Code (`.vscode/launch.json`) or `chrome://inspect`.
- To test another player, add its process name (without `.exe`) to the Players setting
  in the property inspector.

## Checks

The same checks CI runs:

```bash
npm run build
npx streamdeck validate com.z4yross.musicvol.sdPlugin
npx streamdeck pack com.z4yross.musicvol.sdPlugin -o dist
```

## Conventions

- TypeScript, tabs, double quotes, as in the existing files. Source files are UTF-8.
- Conventional commits, single line: `type(scope): subject`, lowercase, imperative,
  no trailing period. Examples: `fix(bridge): respawn helper after timeout`,
  `feat: support tidal`.
- Everything in the repo is in English: code, comments, docs, commit messages.
- Do not change the plugin or action UUIDs; the Marketplace ties the product to them.
- No brand logos in icons; generic shapes and colours only.
- Keep the touch-strip layout inside 200×100 and under 10 updates per second (Elgato
  guideline).

## Pull requests

1. Fork and branch from `main`.
2. Make the change, run the checks above, test it on a real Stream Deck+ with at least
   one player open.
3. Open a PR describing what changed and why, with a screenshot or a short description
   of what the dial shows when the change is visible.

CI builds, validates and packs every PR; the `.streamDeckPlugin` is attached to the run
as an artifact if you want to try the exact build.

## Releasing (maintainers)

1. Bump `Version` in `com.z4yross.musicvol.sdPlugin/manifest.json` (four parts, for
   example `0.3.0.0`).
2. Commit, then tag and push:

   ```bash
   git tag v0.3.0
   git push origin main v0.3.0
   ```

   CI checks the tag against the manifest version, packs the plugin and attaches it to the
   GitHub release.
3. Upload that `.streamDeckPlugin` in Maker Console under **Versions > Create version**.
   The Marketplace has no API; this step is manual.
